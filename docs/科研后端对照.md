# 科研后端对照

这是可选后端，不替换 `platform/model.py` 里的自写运动学。上游是
[generative-robot-design](https://github.com/JonathanKuelz/generative-robot-design)
（MIT，IJRR 预印本 [arXiv:2509.13077](https://arxiv.org/abs/2509.13077)）。
钉住的提交写在 `third_party/generative-robot-design/PINNED_COMMIT`。

论文里的三种参数化在上游是 Hydra 配置，不是三个 Python 类：

- modular：`python main.py`，模块来自 `robot_modules/robco_modules.py`
- economic：`constraints=economic`，DH 参数
- free：`constraints=free`，DH 参数

`ParameterConvention` 只有 `MDH`、`DH`、`ROBCO`。ZBot 用他们的
`Custom(proximal, distal)`：近端变换、绕 z 的关节角、远端变换。
0 和 π/2 是两个远端变换不同的模块 `ZBot_0` / `ZBot_90`，因为 Robco 的 D86 族不是 ZBot。
概念连杆的长度是远端平移，线密度仍是假设的 4 kg/m。实物尺寸锁定。

官方穷举基线在 CPU 上大约每任务数小时，这里没有跑。也没有训练设计网络。
`numerical_ik` 绑在 CoBRA 的 `NetworkInput` 上，所以梯度精修是对他们的可微正运动学做阻尼最小二乘，再加几步 Adam。

## 安装

不要装进现有 mjlab 环境。另建虚拟环境：

```bash
python3 -m venv .venv-research
.venv-research/bin/pip install -r requirements-research.txt --extra-index-url https://download.pytorch.org/whl/cpu
PYTHONPATH=src:third_party/generative-robot-design .venv-research/bin/python scripts/research_campaign.py
PYTHONPATH=src:third_party/generative-robot-design .venv-research/bin/python -m unittest tests.test_research_backend
```

`requirements-research.txt` 锁定 `numpy<2`、`pin==2.7.0`、`hpp-fcl>=2.4,<3`。
PyPI 上的 `timor-python` 1.1.1 会因 Boost 动态库导入失败，本对照没有依赖它。

## 验证

6 模块全 0，多组关节角，足底和关节原点相对 `ZBOT6.xml` 的 MuJoCo 误差约 1e-11 m，低于 1e-6 m。
7、8 模块相对本平台导出的 MJCF，经 MuJoCo 读出的末端误差约 1e-10 m。

默认盒 1 cm、125 点，带胶囊和静力矩：端点 123/125，单元中心 125/125。
批次 2 的自写 IK 是 120/125 和 125/125。中心点相同，端点多 3 个，是求解器差别。没解出的格点不是不可达。

32 种 6 模块接口，和批次 2 的 27 点、2 cm 分数比，Spearman 0.51，Kendall 0.46。
新后端大量打满 26/27 或 27/27，方差更小，所以相关不是很高，但也不是负相关。

弯臂上 Pinocchio RNEA 的 4 kg 静力矩裕度：6 模块 6.51 N·m，7 模块 4.00 N·m，8 模块 0.47 N·m。
伸直零位的裕度接近 20 N·m，不能拿来判断重载。hpp-fcl 在一组展开姿态上没有非相邻网格碰撞。

不依赖 6 模块零位姿的 12 个六维目标（4 个位置，世界系单位阵、绕 x 60°、绕 y −40°，1 cm 和 5°）：
6 模块 10/12，7 模块 9/12，8 模块 7/12。
批次 3 那组含零位姿的 16 个目标上，7 模块是 12/16、8 模块是 6/16。
7 模块是否更适合姿态，取决于目标集。8 模块在两组里都更差。

概念连杆的 pymoo 只跑了每个驱动数种群 8、2 代。前沿里有大约 3.6 kg 的假设质量，27 点可行比例约 0.67，低于 6 模块实物。不能写成硬件减重，也没有因此加长搜索。
